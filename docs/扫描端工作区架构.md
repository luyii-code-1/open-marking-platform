# 扫描端项目工作区

扫描端采用Windows .NET 10 + WebView2，控制HUAGAOSCAN Hi-5100S等扫描仪。在线加载服务端`/scanner.html`，断网或服务端页面不可用时加载随包离线页面。已下载的项目配置、本地识读引擎和队列可随客户端重启恢复。

## 操作层级

按考试项目 → 科目 → 题卡组 → 扫描批次逐级进入，面包屑保留当前上下文。唯一默认组直接进入组内批次列表。首页显示服务器考试和本机已下载项目，下载配置后打开工作区。批次页集中提供设备设置、扫描或图像导入、原图/切题预览、异常处理和同步。

在线与离线页面共用React/TypeScript界面。字号和控件尺度沿用管理端设计，项目/批次默认10条分页，页面记录每页50条。界面和实际操作体验由用户本人审查。

## 职责分工

| 部分 | 负责内容 |
| --- | --- |
| 服务端 | 考试/科目/组目录、已发布题卡几何配置、应考名单快照、设备授权、上传校验、正式计分和业务入库 |
| 网页 | 项目式操作、预览、异常提示和进度，通过专用消息桥调用客户端 |
| .NET宿主 | TWAIN/WIA/eSCL扫描、自动双面判序、CNG设备身份、本地SQLite与文件、引擎监督、上传重试 |
| 随包Python/OpenCV引擎 | 旋转与二维码、四角定位及校正、考号和客观题填涂识读、缺考标记、各题区域裁切 |

识读核心位于`server/omr.py`，供本地引擎和服务端异常恢复共用。客户端读取填涂选项，标准答案和给分规则保留在服务端。正常上传后，服务端核对设备、归属、题卡版本、文件哈希、图像尺寸、题号/选项与切题清单，再按正式规则计分。

## 本地通信和设备身份

网页使用WebView2结构化消息桥，限定连接、下载项目、创建批次、发现设备、开始/停止、配页、核查、重试和预览等命令。宿主只接受所配置服务端扫描页面及内置离线页面的消息；桥协议为`omp-scanner-3`，服务端页面协议不兼容时回到随包页面。

宿主与识读进程使用随机端口的127.0.0.1 TCP Socket。每次启动生成会话密钥，经继承管道传入，不写入命令行、工作区或日志。消息采用4字节长度和JSON，限制大小，限定`ping/recognize/stop`命令。完整图像通过本机工作区文件引用传递，界面只接收预览缩略图。

引擎随包携带Python运行时和OpenCV等依赖，扫描电脑无需安装Python。设备身份沿用Windows用户范围不可导出的CNG私钥，短期令牌由宿主持有。WebView2关闭密码保存和通用自动填充。

## 配置快照和离线工作

`GET /api/v1/scanner/catalog`提供目录；`GET /api/v1/scanner/projects/{id}/package`提供科目、可用组、题卡版式和应考名单快照，不包含答案与分值。每组保存题卡UUID、修订号、引擎版本及配置SHA-256。

本地配置按服务端地址指纹和项目UUID隔离，保存为`workspaces/<服务端指纹>/<项目UUID>/package.json`。SQLite集中登记批次、所属项目/科目/组、捕获UUID、正背面顺序、状态和配置快照；图像按批次及捕获UUID保存。连接设置显示本机数据目录，便于备份。

离线时可在已下载项目中新建批次、扫描、识读、核查与配页。本机生成批次UUID，联网后幂等登记原编号。重新联网时发现旧版本、删除、冻结或归属冲突，暂停该批次并保留本地文件；缓存快照不替代服务器接收校验。

## 图像、上传和配页

已交付到客户端的图像先落盘，保留原始PNG和上传JPEG，再写持久队列。质量检查及双面判序沿用现有规则，本地引擎生成校正PNG、识读JSON和题目区域PNG切题包。停止采集时，当前已交付图像仍完成落盘与处理。

客户端按考号及正背面顺序建立本地配页清单，检查缺面、重复/不清考号及下载的应考名单，操作员核对纸张后确认。采集、识读与上传分开，网络中断保留队列。每页原图、校正图和切题包校验后上传，收到服务器持久确认才标记已上传。相同捕获UUID重试不会重复创建页面，切题ZIP使用固定条目时间保证重复识读结果稳定。

本地配页完成后继续上传剩余文件，服务端逐项核对本地清单和接收页面，再生成正式答卷。服务器确认前客户端显示等待同步；正式计分与审计由服务器办理。

质量不通过时可查看原图、排除后重扫，或显式上传原图和质量报告供管理员核查。人工定位或排除后，刷新服务端状态继续。自动双面排除按整张纸办理，保留原图。服务端删除不会远程删除扫描电脑的采集原件。

## 文件与历史

服务端每页保存`pages/<捕获UUID>.image`、`.png`及`.cuts.zip`。切题包按题目/区域索引保存PNG；阅卷依据页面版本和区域使用已上传切题图，同题多区域继续拼接。人工定位或区域更正后的版本按当前区域处理。

三类文件均纳入远端镜像、归档、按哈希回取、备份恢复、空间释放和层级删除。清理先校验归档，范围按考试/科目/组归属。异常核查继续支持服务端识读和人工四点定位。

## 构建与验证

先构建Web页面，再以.NET 10构建扫描端。引擎构建依赖见`scanner_engine/requirements-build.txt`；预览打包脚本将引擎及其运行时放入`recognition/`，网页放入`ui/`。安装包随带.NET 10运行时，运行扫描程序仍需WebView2 Runtime及厂商驱动。

无窗口联调：`python -m tools.desktop_scanner_smoke`。测试先下载项目，停止测试服务器，重新创建客户端实例完成本地双面识读及配页；服务器重启后再次打开客户端，验证持久队列、设备签名、上传与正式结分。使用`--scanner-dll <解压目录>/OMP.Scanner.dll --bundled`可验证实际解压包的随包引擎。

平台依据：[WebView2网页与原生通信](https://learn.microsoft.com/en-us/microsoft-edge/webview2/how-to/communicate-btwn-web-native)、[WebView2来源和消息边界](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/security)。Hi-5100S实机驱动、进纸、停止和出图顺序按《扫描端》现场验收。
