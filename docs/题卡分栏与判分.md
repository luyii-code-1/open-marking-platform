# 题卡分栏、扫描绑定与逐题判分

新题卡使用版式版本3。A4纵向打印；A3横向可选2×2（正反面各2栏）或3×3（正反面各3栏），每栏按内容顺序续排。标题和副标题只显示在整份题卡的第一栏，在该栏内居中。首栏保留考生信息、准考证号及监考缺考标记，考号右侧留给考生须知和填涂说明，不生成禁答区；其余栏从35毫米开始使用。栏间保留间隔和分隔线，每栏有顺序编号。

客观题默认每5题一组，组内从上往下编号，再到右侧一组；一排放满后往下，当前栏不足续到下一栏，再到背面。A4及A3双栏模板默认每栏4列客观题，A3三栏模板默认每栏3列，可在重新排布时调整。选项方括号宽4毫米、高2.3毫米，中心距5毫米；行距4.8毫米，五题组之间留3毫米。排布避让已有主观题区；空间不足整批拒绝。主观题继续支持手工框选、同题多区域和逐题微调。

题卡标题、副标题、缺考标记说明、栏号和富文本均通过随项目提供的字体嵌入PDF，不依赖查看器安装中文字体。打印稿不显示打印提示；五级灰度块位于右上定位点左侧，不附说明文字。识读同时兼容之前版本的页脚灰度条。打印时使用实际大小并保留定位标记。

各栏正文中剩余的较大空白自动生成“该区域禁止答题”占位，使用浅色边框和交叉线。仅处理宽度至少30毫米、高度至少12毫米的剩余矩形，避开已设置答题区及其附近、考生信息、定位标记和页脚灰度条；五题组间距和主观题内部留白保留。添加或移动答题区域后，占位随打印预览自动重新计算。

## 人工选择题卡及自动双面

扫描员先选择考试、科目、题卡组；创建批次时固定该组已发布题卡的编号、修订号和配置哈希。新卡不印二维码，识读依据该批次下载的配置；服务器继续校验题卡版本与归属。

双面题卡默认一次进纸采集两面。先用可区分正反面的样张确认驱动输出为“正面先出”或“背面先出”，创建批次时选择校准结果并持久保存；同批次保持放纸方向。驱动关闭跳空白、图像拆分及多流，确保每张纸连续输出两面，背面方向应在驱动中校正。纸张数量和先出面由操作员核对，系统无法自动发现所选题卡错误或符合交替顺序的混卷。

缺面、停止或重启后，先检查每张纸两面是否齐全。未齐全时排除整张后重扫，不能把下一张纸接到上一张缺面。已有已发布的版本1/2题卡按原配置继续处理；改用新版时复制为草稿、重新排布、发布并重新下载配置。新版桥协议为omp-scanner-4，识读引擎为omp-omr-3，需要更新客户端安装包。

## 逐题判分与试算

在客观题的详细设置中配置，使用服务端正式计分函数试算当前标准答案和作答，得分限制为0至本题满分。支持：

- `exact`：全部正确得满分。
- `partial`：正确子集给`partial_points`，全对满分，出现错选为0。
- `per_option`：每个正确选项加`correct_points`；`wrong_action=deduct`时，每个错选扣`wrong_penalty`，设为0即错选不扣分；`wrong_action=zero`时有错选整题为0。

示例：正确答案AC，满分2分。下面的规则对AB给1分、AC给2分：

```json
{"mode":"per_option","correct_points":1,"wrong_penalty":0,"wrong_action":"deduct"}
```

将`wrong_action`设为`zero`，AB即为0分，单选A仍为1分。高级JSON先校验再应用；规则不执行脚本。规则与标准答案只保存在服务器，不下发到扫描端。

## 须知模板

考生须知和填涂须知等待用户提供全科清晰参考原稿后逐字整理，作为后续自动添加的模板；本轮先交付默认分栏和客观题排布。

示例配置、交付文档和验证报告使用中性主机、用户名及路径。实际连接由部署配置和用户填写的数据决定。
