# 考试工作区导航

日期：2026-11-12。

考试按“考试项目 → 科目 → 题卡组”逐级进入，面包屑保留完整所属路径。新建科目自动归入当前考试，新建组自动归入当前科目；批量导入使用当前页面的模板，父级也由页面固定。

## 考试项目

项目内提供科目列表、跨科成绩、归档与释放。科目可统一使用一份题卡，或按学校、年级、卷别分组。统一题卡且只有一个默认组时，进入科目直接打开默认组工作台；面包屑仍显示科目。自定义分组科目先显示其组列表。

## 题卡组

组工作台提供题卡设计、应考名单、扫描与补扫、阅卷、异常核查和成绩入口。各功能固定当前组，避免重复选择所属考试。题卡尚未发布时，扫描与阅卷入口引导先配置题卡。

题卡编辑中的新建、复制、从题卡库创建均归属当前组。组内切换功能保留已打开的编辑页；带未保存题卡离开工作区或刷新时提示确认。

导航位置写入地址，支持复制深链接、刷新和浏览器前进后退。地址中的科目必须属于当前项目，组必须属于当前科目；不匹配时显示返回入口。

## 全局入口

侧栏按考试工作、基础管理和个人账号组织。全局阅卷、异常总览和成绩总览用于跨考试查看，选择题卡组时按考试、科目、组逐级选择，区分同名记录。

人员管理按班级与任教关系、学生、用户账号分类，各分类内统一提供创建、导入和编辑。系统设置按扫描设备、赋分方案、操作记录分类。常规列表默认每页10条，可搜索和切换每页数量；批量导入、刷新放入更多操作。

## 验证范围

导航逻辑检查覆盖深链接、父子归属、默认组、固定父级创建与导入、同名组选择。构建与PWA检查单独执行。页面视觉、交互手感及实际业务操作由用户审查；开发过程中未使用浏览器或电脑控制。
