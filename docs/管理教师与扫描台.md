# 管理教师、扫描台与考场标签

系统包含系统管理员（`admin`）、管理教师（`manager`）和阅卷教师（`teacher`）三个账号角色；扫描设备使用独立设备身份。

| 能力 | 系统管理员 | 管理教师 | 阅卷教师 |
| --- | --- | --- | --- |
| 考试、题卡、名单、扫描、异常、阅卷分配、成绩与项目归档 | 全部 | 全部 | 按分配阅卷、查看任教班级已发布成绩 |
| 普通教师账号维护及重置密码 | 可 | 可 | 个人资料及个人密码 |
| 系统管理员和管理教师账号、角色授予 | 可 | 系统管理员办理 | 系统管理员办理 |
| 存储连接维护、设备停用/重新启用、全局赋分方案、审计与全站数据库备份 | 可 | 系统管理员办理 | 系统管理员办理 |
| 为考试选择已有存储连接、使用已有赋分方案 | 可 | 可 | 按成绩查看范围 |
| 扫描台下载客户端、生成配对码 | 可 | 可 | 管理人员办理 |

管理教师可登录管理后台及阅卷台。管理后台登录后进入“扫描台”，考试、人员等入口保留。系统设置及其服务端接口仅系统管理员可访问。账号权限按当前数据库角色校验，管理角色被撤销后，名下设备的后续请求也会被拒绝。

## 扫描台与首次配对

1. 登录管理后台，在扫描台下载Windows x64安装包。
2. 安装到当前Windows用户的程序目录；安装包包含.NET 10运行时、离线网页与Python/OpenCV识读引擎，扫描仪厂商驱动与WebView2 Runtime需在电脑上可用。
3. 点击“连接本机扫描端”，生成10分钟有效的一次性配对码，点击“唤起扫描客户端”。Windows通过`omp-scanner://connect`唤起；若未唤起，可在客户端填写服务器与配对码。
4. 客户端确认服务器地址后注册本机CNG公钥，接着使用设备挑战签名建立连接。后台登录令牌和账号密码不通过唤起地址传给客户端。
5. 后续启动自动连接已绑定服务器；下载项目配置后可离线重启、扫描、识读、配页与排队续传。

生成新配对码会使本账号之前尚未使用的码失效。配对码只保存哈希，成功使用后不能复用。设备已绑定其他账号或已停用时，由系统管理员处理。应用使用单实例和当前Windows用户范围的命名管道传递唤起请求；采集或同步期间不切换服务器。

网页消息桥协议为`omp-scanner-4`，原设备签名协议及本地持久队列保留。旧网页与宿主不兼容时使用随包页面，使用本轮配对及标签功能应更新安装包。

## 发布下载包

`python -m tools.package_preview --output 新目录`构建源码ZIP、扫描端ZIP及Windows安装包；Windows构建机需要.NET SDK、Node/npm、Python构建依赖和Inno Setup（`ISCC`）。

将安装包发布到服务器数据目录：

```text
python -m tools.publish_scanner_distribution 安装程序.exe --directory /data/scanner-distribution --version 版本号
```

该目录通过数据卷持久保存，也可用`OMP_SCANNER_DISTRIBUTION`指定其他目录。发布工具写入文件名、大小、SHA-256及版本清单；同名不同内容会拒绝覆盖。安装包尚未发布时，扫描台显示未就绪。下载链接有效120秒，下载时再次核对账号当前权限与包版本。

安装按当前用户进行，协议注册在HKCU；卸载清理程序和协议注册，采集队列保留在原用户数据目录。浏览器首次唤起可能要求用户确认，具体界面由用户验收。

## 考场标签

在“考试项目 → 考场标签”新增、修改名称或停用标签。每个考试独立维护，同考试名称唯一；每批可选最多20个标签，跨考试标签会拒绝。原有考场备注继续保存。

批次记录标签编号和名称快照，配页后的答卷继承标签。后续改名不改变既有快照；停用后新选择列表不再推荐，但已有批次及离线缓存仍可按原编号同步。补扫更换或补齐页面时，答卷标签按当前页面来源重新汇集。

扫描批次、异常、成绩可按标签筛选并导出CSV。成绩分析先遵循原任教范围与赋分口径，再按标签筛选；标签不授予额外数据权限。标签属于考试归档及删除范围，删除科目或题卡组保留考试标签。离线项目快照和本地SQLite均保存标签配置与批次选择。

安装与协议依据：[Inno Setup当前用户安装](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm)、[注册表条目](https://jrsoftware.org/ishelp/topic_registrysection.htm)。
