# 赋分方案

管理员在“系统设置 → 赋分方案”建立、编辑或另存方案，再绑定到指定考试/科目/题卡组。题卡组已发布时需先进入复核流程，不能直接更换方案。

支持原始分分段、百分位分段与外部对照表。真实学生的赋分从40分起，分段及对照关系不允许高原始分对应更低赋分。学校的比例和档位由管理员输入，不预设为某个校方或地区的正式方案。

## 分段及百分位

原始分分段按区间线性换算；百分位分段先按全组已完成实考成绩计算百分位，再按区间换算。同分的当前计算方式为居中百分位：低于该分的人数加同分人数的一半，再除以有效人数。缺考、未扫描及未完成成绩不参加百分位计算。

可选择结果保留0、1或2位小数，使用四舍五入。相邻区间共用端点时，可以指定归入较低或较高原始区间。默认沿用2位小数、较低区间；正式使用前按校方规定选择。具体校方比例、同分处理及舍入口径仍待确认。

## 对照表导入

可读取CSV/TSV，或直接粘贴Excel两列文本。Excel工作簿需另存为CSV；编码支持UTF-8（含BOM）和GB18030。上传上限2MB。

表头使用 `原始分,赋分`，也支持 `raw_score,converted_score` 等同义表头。原始分应非负且最多两位小数，重复数值会被拒绝，例如50与50.00视为同一个分值。空行忽略；列数、非数字、倒挂或低于40的赋分会提示修正。

读取或粘贴后先校验并预览，点击保存才建立方案。对照表逐分匹配，不自动插值或填补缺失项。绑定或修改时会检查当前已有的完成成绩是否都能转换；未来出现未列出的分数时，需要补齐表后再发布。建议使用校方提供的完整对照表；统计满分取方案中最高赋分，因此部分表也会影响统计分母。

缺考仍按0分处理，不套用40分起的对照关系；未扫描成绩保留空值，不能转换为0或40。

## 修订与发布

未被已发布组使用的方案可填写修改原因后编辑。系统核对编辑时的版本号，避免其他管理员的修改被覆盖，并检查已绑定组的现有分数覆盖情况。

方案被已发布组使用后锁定，通过“另存副本”建立新的独立方案。成绩发布时保存采用的完整定义和版本；已发布统计读取该快照。需要调整时先复核、修改或绑定方案，再重新发布。原始分、评分流水和修改审计继续保留。

项目归档包含使用的赋分方案及发布快照。方案编辑和绑定会触发相关管理页面刷新，当前未保存的表单保持原状。

开发用例覆盖导入编码/格式、重复数字、40分下限、同分百分位、缺考和未扫描、舍入与端点、版本冲突、覆盖检查、冻结与归档快照。校方规则和实际界面体验仍需用户验收。
