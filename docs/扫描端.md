# Windows扫描端

客户端采用.NET 10 + WebView2，在线加载服务端扫描页面，离线使用随包页面。按考试项目、科目、题卡组和批次逐级办理；本机完成定位、识读、配页及切题，队列上传后由服务端校验与正式计分。工作区、配置快照和Socket协议见《扫描端工作区架构》。

## 首次注册与日常连接

1. 服务器使用有效HTTPS地址；仅本机调试允许HTTP。客户端使用系统证书验证，不提供忽略证书错误开关。
2. 系统管理员或管理教师登录管理后台“扫描台”，下载安装包，生成一次性配对码并点击唤起客户端；未唤起时在客户端连接设置中填写服务器和配对码。本地生成Windows用户范围P-256 CNG密钥，私钥禁止导出。
3. 配对完成后使用设备挑战签名自动连接。下载考试项目配置后，可断网并重新启动客户端继续扫描，联网后继续上传。
4. 系统管理员在“系统设置 → 扫描设备授权”查看设备和公钥指纹、停用或重新启用。重新启用需验证系统管理员密码并说明原因，旧访问令牌不会恢复有效。

设备身份按服务器地址与Windows用户隔离。设备令牌有效15分钟，客户端按单调时钟提前续期。停用设备或撤销授权管理员角色会立即阻止后续请求。

## 批次与队列

选择已发布题卡组后创建批次。双面题卡默认自动双面，使用ADF一次进纸连续采集两面；也可选择分面采集，按正面整批、背面整批采集并由操作员确认同/逆序。单面题卡使用分面采集中的正面入口。批次建立后采集方式固定，旧批次保留分面方式。

自动双面要求驱动连续输出每张纸的两面。创建批次时选择试扫确认的“正面先出”或“背面先出”，设置随批次持久保存，后续进纸保持同一顺序。两面使用同一纸张序号，完成后才开始下一张。新题卡由操作员选择题卡组及已发布版本，按该版本配置识读。

结束、停止或重启后继续采集前，必须每个有效纸张序号均有完整两面。缺面时应在管理端排除该整张纸已采集的页面，再整张重扫；不能直接放入下一张纸补齐。排除原图仍保留，重扫使用新的序号。配页前再次检查完整性，并显示实际序号供人工确认。导入双面序列时，多选文件按文件名排序，多页TIFF按帧顺序读取，同样要求每张纸两面相邻。

人工选定题卡不能自动发现混卷或所有跨学生错配。必须核对实物张数、放纸方向、正反面顺序，并先完成下述试扫。

原始PNG及上传JPEG先落盘并刷新磁盘，再写SQLite队列；上传前核对JPEG的SHA-256。捕获UUID用于服务端幂等，网络错误保留待上传记录。

设备只可访问所属扫描批次。早期未绑定设备的本地批次，在管理员注册设备时关联；更换Windows用户或电脑导致密钥变化时，应先在管理端停用旧设备，再迁移待扫批次到新设备，原捕获编号及扫描文件保留。

管理端排除的页面同步为“已排除”，保留原图但不计入配页数量。定位异常、考号不清或发布冻结会停止本地批次；管理员处理后点击“刷新批次状态”恢复。定位异常可在管理端四点定位恢复，明确混入其他题卡时应排除混卷。

每页原图先落盘，再检查批次题卡绑定、四角定位标记、有效分辨率、清晰度与上传文件大小。异常页及检查依据写入持久队列，冻结批次并停止后续采集或导入；重启后仍保留。四角检查支持旋转，清晰度使用缩至最长1800像素后九个分区的最大拉普拉斯方差，避免整页空白区稀释结果。该指标用于提示人工核查，需要真实扫描样本调校，不能覆盖所有纸张破损或内容缺失。

质量选项保存在本地队列目录的 `quality-options.json`，每次入队读取，支持 `CheckQr`、`CheckCorners`、`CheckSharpness` 开关及 `MinDpi`、`MinSharpness` 阈值；新题卡按人工绑定处理，`CheckQr`仅用于旧版题卡；默认150 DPI、清晰度35。DPI允许100至600，清晰度阈值允许0至10000。配置无效会保留页面并标记检查未完成。

正常页面在本机完成识读和切题后进入队列。异常页通过行内“更多操作 → 上传原图供核查”，在确认后将原图及质量报告送交管理员；此路径可使用服务器识读和人工四点定位，并创建核查记录、冻结批次。管理员处理后，客户端“刷新服务端状态”继续。已排除页保留原图并同步排除状态，不计入配页。SHA-256不符仍阻止上传，单个文件超过30MB需重新扫描或处理。

## HUAGAOSCAN Hi-5100S 接入与现场试扫

用户已确认Hi-5100S通过Windows USB连接，优先自动双面；当前电脑尚未安装厂商驱动。厂商资料列出A3、双面、USB及TWAIN支持，客户端默认选择TWAIN，采集设置为300 DPI灰度、保留空白面。资料中的100页/分、200面/分针对200 DPI，300 DPI实际速度须现场测量。参考[厂商型号参数](https://www.huagaochina.cn/argument.html?cid=0&id=8)、[厂商下载页](https://huagaochina.cn/download.html)。

1. 安装对应Windows版本及架构的厂商驱动，记录版本和可见TWAIN设备名；驱动版本需以现场实际安装包为准。
2. 在驱动中关闭跳过空白页、图像拆分、多流输出，确保每张纸只输出两面；关闭会截掉四角标记的自动裁切。
3. 用两张有明显手写区分的双面题卡，先确认输出为正1/背1/正2/背2，或背1/正1/背2/正2。整批正面后整批背面的输出应改用分面批次。不能仅凭文件奇偶判断扫描面。
4. 分别验证A4和A3实际装纸方向、背面180度旋转、四角完整、考号、配页与整卷内容对应。新题卡需在驱动中校正背面方向，并保持同批次放纸方向一致。
5. 验证中途停止、缺面、混入其他题卡后的原图保留与整张重扫；完成后再增加纸量，测量吞吐和卡纸恢复。

WIA、TWAIN、ESCL发现及ADF/自动双面采集已有代码。当前已完成软件模拟联调，真实Hi-5100S驱动、连续进纸、停止行为及质量阈值尚未验收。

## 设备协议

- 公钥：P-256，SPKI DER，Base64URL无填充。
- 挑战：60秒、一次性。设备签名消息为UTF-8：`OMP-SCANNER-1\n<challenge_id>\n<nonce>\n<device_id>`。
- 签名：SHA-256/ECDSA，RFC3279 DER序列，Base64URL无填充。
- 设备访问令牌仅支持扫描元数据、创建本机批次、读批次/页面、上传及配页。人员、成绩、标准答案及管理接口不接受设备令牌。
- 签名失败也消耗挑战；每设备每分钟最多5次挑战。令牌只以哈希保存，停用及重新启用使旧令牌失效。

Windows接口依据：[ECDsaCng](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.ecdsacng?view=net-8.0)、[签名格式](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.dsasignatureformat?view=net-8.0)。

## 不启动窗口的联调

```powershell
dotnet build scanner/OMP.Scanner.csproj --no-restore --nologo
.\.venv\Scripts\python.exe -X utf8 -m tools.scanner_smoke
```

脚本使用独立临时目录、随机本机端口和临时FastAPI服务，生成打印样本，通过实际.NET程序验证：CNG私钥禁止导出、设备签名、队列落盘后重开、四方向旋转、二维码正背面混入、模糊、缺角、异常页持久冻结、SHA-256损坏拦截、JPEG上传、关闭旧连接后重新打开密钥、接口权限与批次配页结分。自动双面覆盖正面/背面先出、跨次顺序改变、重复面、缺面拦截、模式持久化、强制二维码检查、整张排除重扫及双面上传配页结分。结束后停止临时服务并清理自检密钥；不启动扫描窗口、不操作设备。

正式目标已按用户确认改为.NET 10（`net10.0-windows`），Microsoft.Data.Sqlite同步采用10.0.15。本机独立SDK 10.0.404编译0警告0错误，CNG、持久队列、双面判序、JPEG上传与配页无窗口联调通过。新安装包随带.NET 10运行时；本地源码构建仍需.NET SDK。Hi-5100S实机驱动与进纸验收仍待完成。
