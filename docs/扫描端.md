# Windows扫描端

## 首次注册与日常连接

1. 服务器使用有效HTTPS地址；仅本机调试允许HTTP。客户端使用系统证书验证，不提供忽略证书错误开关。
2. 首次填写管理员账号密码，点击“管理员登录并注册设备”。本地生成Windows用户范围的P-256 CNG密钥；私钥禁止导出，登记文件仅保存设备UUID。用于注册的管理员会话随后登出。
3. 之后可直接点击“已注册设备连接”，通过一次性挑战签名连接服务器，不需在磁盘保存管理员密码或长期令牌。
4. 在“系统设置 → 扫描设备授权”查看设备与公钥指纹、停用或重新启用。重新启用需验证管理员密码并说明原因，旧访问令牌不会恢复有效。

设备身份按服务器地址与Windows用户隔离。设备令牌有效15分钟，客户端按单调时钟提前续期。停用设备或撤销授权管理员角色会立即阻止后续请求。

## 批次与队列

选择已发布题卡组后创建批次。双面按正面整批、背面整批采集，同/逆序由操作员确认。原始PNG及上传JPEG先落盘并刷新磁盘，再写SQLite队列；上传前核对JPEG的SHA-256。捕获UUID用于服务端幂等，网络错误保留待上传记录。

设备只可访问所属扫描批次。早期未绑定设备的本地批次，在管理员注册设备时关联；更换Windows用户或电脑导致密钥变化时，应先在管理端停用旧设备，再迁移待扫批次到新设备，原捕获编号及扫描文件保留。

管理端排除的页面同步为“已排除”，保留原图但不计入配页数量。定位异常、考号不清或发布冻结会停止本地批次；管理员处理后点击“刷新批次状态”恢复。二维码损坏可在管理端四点定位恢复，明确混入其他题卡时应排除混卷。

每页原图先落盘，再检查二维码及题卡版本/正背面、四角定位标记、有效分辨率、清晰度与上传文件大小。异常页及检查依据写入持久队列，冻结批次并停止后续采集或导入；重启后仍保留。四角检查支持旋转，清晰度使用缩至最长1800像素后九个分区的最大拉普拉斯方差，避免整页空白区稀释结果。该指标用于提示人工核查，需要真实扫描样本调校，不能覆盖所有纸张破损或内容缺失。

质量选项保存在本地队列目录的 `quality-options.json`，每次入队读取，支持 `CheckQr`、`CheckCorners`、`CheckSharpness` 开关及 `MinDpi`、`MinSharpness` 阈值；默认150 DPI、清晰度35。DPI允许100至600，清晰度阈值允许0至10000。配置无效会保留页面并标记检查未完成。

点击“上传 / 重试”可在明确确认后把本地待处理页面及检查结果送交管理员核查。服务器仍独立执行二维码、定位和考号识读，并为质量问题创建异常，冻结批次；管理员填写核查结论，再恢复批次，客户端刷新后继续。已排除页保留原图，不重新进入上传队列。SHA-256不符仍阻止上传，超过30MB的文件需要重新扫描或处理。

WIA、TWAIN、ESCL设备发现和ADF采集已有代码，实际型号及驱动兼容性尚未验收。

## 设备协议

- 公钥：P-256，SPKI DER，Base64URL无填充。
- 挑战：60秒、一次性。设备签名消息为UTF-8：`OMP-SCANNER-1\n<challenge_id>\n<nonce>\n<device_id>`。
- 签名：SHA-256/ECDSA，RFC3279 DER序列，Base64URL无填充。
- 设备访问令牌仅支持扫描元数据、创建本机批次、读批次/页面、上传及配页。人员、成绩、标准答案及管理接口不接受设备令牌。
- 签名失败也消耗挑战；每设备每分钟最多5次挑战。令牌只以哈希保存，停用及重新启用使旧令牌失效。

Windows接口依据：[ECDsaCng](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.ecdsacng?view=net-8.0)、[签名格式](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.dsasignatureformat?view=net-8.0)。

## 不启动窗口的联调

```powershell
dotnet build scanner/OMP.Scanner.csproj --no-restore --nologo
.\.venv\Scripts\python.exe -X utf8 -m tools.scanner_smoke
```

脚本使用独立临时目录、随机本机端口和临时FastAPI服务，生成打印样本，通过实际.NET程序验证：CNG私钥禁止导出、设备签名、队列落盘后重开、四方向旋转、二维码正背面混入、模糊、缺角、异常页持久冻结、SHA-256损坏拦截、JPEG上传、关闭旧连接后重新打开密钥、接口权限与批次配页结分。结束后停止临时服务并清理自检密钥；不启动扫描窗口、不操作设备。

当前代码以.NET 8构建并通过本机验证。微软已于2026-11-10结束该版本支持，正式发布的.NET 10 LTS目标正在等待用户技术栈确认；参见[微软支持公告](https://devblogs.microsoft.com/dotnet/dotnet-8-9-end-of-support/)。
