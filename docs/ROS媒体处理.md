# ROS 媒体处理接入核对

资料来源：用户于2026-11-12粘贴的“媒体处理 Beta”控制台参数说明及随后授权使用的测试桶。Beta期间暂不收费、正式上线另行通知为资料中的当时说明，实际计费以服务商届时公告为准。

## 已确认的参数说明

| 参数 | 含义 |
| --- | --- |
| `rect=x,y,w,h` | 在原图中按像素裁切，先于缩放执行 |
| `w`、`h` | 目标宽高，单位像素 |
| `dpr` | 尺寸倍率，默认1 |
| `mode=clip` | 等比装入目标框 |
| `mode=crop`、`pos` | 铺满后裁切及保留位置；默认crop |
| `fmt` | jpg/jpeg、png、webp、avif、gif |
| `q` | JPEG/WebP/AVIF质量1–100，PNG基本忽略 |

说明还列出锐化、模糊、文字与图片水印；本次接入目标是阅卷题图的坐标裁切与按需缩放。

## 与当前系统的衔接

题卡区域使用毫米，校正图固定每毫米4像素。应当基于校正图裁切；原始扫描图尚未校正，不能直接使用题卡区域坐标。沿用现有Pillow裁切边界：`left=int(x*4)`、`top=int(y*4)`、`right=int((x+width)*4)`、`bottom=int((y+height)*4)`；ROS矩形为`left,top,right-left,bottom-top`。例如区域`x=15,y=110,width=90,height=20`对应`rect=60,440,360,80`。

扫描端上传的切题包继续优先使用；ROS可用于远端校正图的单区域按需裁切。多区域、跨面作答仍需按现有顺序拼接，该说明没有列出拼接接口。特殊卷覆盖图片继续按其独立资产处理。

`/tasks/{id}/image`由服务器校验任务权限后转发题图。媒体功能按存储连接独立开启，默认关闭；开启时服务器为包含`rect`与`fmt=png`的请求签名并向媒体地址取图，核对尺寸后参与现有多区域拼接。失败、超时、返回原图或尺寸不符时，使用原连接取回经SHA-256校验的校正图，在服务器裁切。预签名URL及整页图不交给阅卷教师。该模式仍占用应用服务器向教师发送题图的出网带宽。

## 连接维护与考试归属

管理员在“系统设置 → 存储连接”添加或编辑S3/MinIO及ROS连接，可分别测试读写删除和媒体裁切。测试只创建并清理随机临时对象，不枚举、覆盖或删除已有对象。Access Key与Secret Key加密保存，列表与编辑响应不返回原值；编辑留空保留原凭据。

每个考试在“存储设置”选择连接，新同步文件保存连接编号、位置及内容哈希；更换项目连接后，已有文件继续从各自原连接读取和清理。同一文件在多个连接有副本时，释放及层级删除覆盖各登记副本。被项目或文件引用的连接不能删除；已有文件登记的连接更换端点、桶或前缀时应新增连接，凭据可原位更新。

凭据解密密钥位于数据目录的`private/storage.key`，Linux目录权限0700、文件0600。数据库备份含加密凭据，不含该密钥；运维需将密钥单独保存在受控备份中。恢复到新目录时一并恢复密钥，或在后台重新录入连接凭据。项目归档不导出存储凭据。

## 实际端点核对

2026-11-12授权测试桶独立临时PNG的写入、原字节回读与删除通过；未签名请求返回403。API路径式地址及桶访问域名均接受包含处理参数的签名请求，但`rect=10,20,30,20&fmt=png`返回的仍为80×60原图，未得到30×20裁切结果。因此媒体功能保持默认关闭，测试应显示“媒体未就绪”；后续服务商调整后可从后台重测，再开启使用。

自动化验证包含连接权限、凭据加密与留空保留、项目切换后的原连接回取、多个远端副本释放、媒体不可用回退及成功转发、签名请求参数和原图尺寸拒绝。公开资料：[雨云Python预签名示例](https://www.rainyun.com/docs/products/ros/practice/python)。
