# Linux 部署与存储

## 启动

在Linux服务器安装Docker Engine与Compose插件，配置域名DNS后：

```sh
cp .env.example .env
# 编辑 .env，设置 OMP_DOMAIN 为域名。
docker compose up -d --build
docker compose logs --tail=100 api worker scheduler
```

API端口仅在容器网络中开放，通过Caddy的80/443端口访问。首次登录创建管理员。生产实例应在首次使用前创建管理员。

SQLite与资产默认保存在宿主机 `data/`，可通过 `OMP_HOST_DATA` 指定本地磁盘目录，API/Worker/调度器共用该目录。不要将SQLite文件放到SFTP/WebDAV/NFS网络挂载上。

## 任务恢复

`OMP_TASK_MODE=celery` 将识别交给Worker；SQLite中的jobs保存状态、尝试次数与执行租约。Redis投递失败不会删除该记录；调度器每15秒重新投递可执行任务。运行中任务租约10分钟，任务重复投递会检查状态。失败重试最多10次，管理员可在 `/api/v1/jobs` 查看并通过 `POST /api/v1/jobs/{id}/retry` 手动重试。

本地开发默认inline模式，可不启动Redis。生产Compose固定使用独立任务模式，图像Worker并发2。

## 存储

默认 `OMP_STORAGE=local`。外部存储配置见 `.env.example`：

- `s3`：S3或MinIO endpoint、bucket、access key、secret key。
- `ros`：使用ROS提供的S3兼容endpoint与凭据；预签名能力需要对实际桶验证。
- `webdav`：HTTPS目录URL、用户名与密码。
- `sftp`：主机、端口、目录、账号或私钥，并提供可信known_hosts。

页面原件和校正图在后台同步到外部存储，页面键按项目目录归类。上传资产先留本地可用副本；外部传输失败在任务列表中显示并重试。远程同步记录不等于已释放本地缓存，缓存清理属于明确管理操作。

S3/MinIO及ROS可在“系统设置 → 存储连接”维护并测试，每个考试项目在“存储设置”选择连接；媒体处理为默认关闭的独立选项。已有文件保留原连接编号，更新项目绑定后仍可从原连接读取和清理。解密密钥`private/storage.key`需单独受控备份，项目归档不导出存储凭据。环境变量方式继续兼容本地、S3/ROS、WebDAV及SFTP；旧环境配置文件在其资产清理完成前仍需保留。

文件回取会核对索引登记的后端及位置指纹（端点、桶、前缀等）。当前配置不匹配时不会用旧对象键请求新位置；有匹配的有效归档时从归档恢复，否则报错并要求恢复原配置或补齐文件。远端下载先写临时文件，对有记录的SHA-256完成校验后再替换本地文件，失败下载会清理临时文件并保留原有本地副本。

## 通行密钥

生产通行密钥使用域名对应的RP ID与HTTPS来源。默认从OMP_DOMAIN计算，可通过OMP_RP_ID与OMP_WEBAUTHN_ORIGINS指定。来源列表用英文逗号分隔，包含协议及实际端口。修改RP ID会影响已有密钥，请在首次注册前确定域名。

本地开发请使用localhost访问；默认允许http://localhost:5173、http://localhost:8000和https://localhost。浏览器支持、设备解锁及真实密钥注册/登录需人工验收；后端有软件认证器生成真实ECDSA签名的回归测试。
