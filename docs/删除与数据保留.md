# 考试层级删除

管理员可从考试项目、科目、题卡组的“更多操作”进入删除。确认后由持久后台任务依次完成：保存最新项目归档、校验归档和扫描文件、清理指定范围内的本地及远端扫描图片、移除业务记录。

## 预览与确认

预览显示考试路径、业务记录和扫描页数量、题目编号、待取消任务、重阅队列及失效的文件释放清单。完整JSON影响清单可下载。填写删除原因、勾选已核对范围后确认；预览有效期10分钟，扫描、评分或关联记录变化需要重新预览。

只有生成预览的管理员可确认；其他管理员可查看清单。同一确认重复提交返回原任务，不重复创建。

正在执行的本考试后台任务或文件释放操作会阻止确认。确认后暂停整个考试的写入，防止归档和清理期间新增扫描、修改题卡或提交评分。相关待执行任务取消，已有释放清单失效；其他组的待执行任务延后至删除结束。该考试已有删除任务时，“更多操作”会打开原任务。

## 影响范围

删除按所有权逐级包含科目、组、题卡、扫描批次、页面、应考名单、答卷、教师分配、阅卷任务、答题图版本、异常与优秀卷、定位及发布/重阅记录。删除科目保留所属考试，删除组保留所属科目及同科其他组。

学生、班级、账号、共享题卡库、赋分方案、图片资产与归档保留。旧业务记录从日常列表与接口移除，原始内容和删除原因保留用于审计。所有已删除业务编号及其题目编号永久退役；创建新记录不能复用旧编号。

原始评分流水与题目结分记录保留；运行分配状态及重阅队列清除。全部文件清理完成后，记录、审计、编号退役及运行状态更新在同一事务完成，任一步失败均回滚。已领取的相关阅卷任务不能继续提交评分。

默认组删除后移除科目的旧默认组关联；返回科目可重新创建默认组，使用全新编号。扫描客户端下一次检查到批次404时冻结本地批次、停止采集，并保留本地原图与队列。

## 扫描文件和归档

任务生成包含最新业务记录、评分流水、结分、人员快照、审计、永久编号及图片的完整项目ZIP。逐文件校验内容及SHA-256后，检查归档覆盖当前待删除记录与评分。全部扫描文件的归档条目、本地校验值及远端登记位置检查通过，才开始清理。

清理仅包含所属页面的原始图和校正图。删除组保留同科其他组图片，删除科目保留其他科目图片；共享底图、人工裁切资产和题卡库保留。即使只删除一个组，也会保存完整项目归档，归档体积与耗时取决于整个项目。

远端按已登记的准确对象键清理，支持S3/ROS、WebDAV和SFTP。登记后端及位置与当前配置不一致时停止，恢复配置后可重试。适配器允许重复删除已不存在的对象。归档ZIP和历史归档均保留，可从“归档文件”下载。

删除窗口显示任务阶段进度；关闭窗口后任务继续运行。网络或进程中断后，文件清理进度持久保存，恢复时继续原任务。归档损坏、文件不一致、存储配置变化会阻止清理。失败时业务记录与考试写入锁保留，管理员核查后使用“重试原任务”继续；部分文件可能已经清理，归档保留这些图片。

记录提交失败会回滚数据库变更，重试完成剩余步骤。文件操作由可恢复任务处理，不能与数据库组成单一原子事务。服务器清理不会远程删除扫描电脑中的采集原件。

删除项目后，已有归档可从管理后台“归档文件”选择原项目下载，ZIP与校验值保持不变。归档文件恢复只处理文件；重新恢复整套历史业务数据应采用删除前的一致数据库备份，在新的数据目录执行《备份与恢复》流程。

## 验证

测试覆盖项目/科目/组范围、父级与同科其他组保留、共享数据和归档保留、评分流水与结分、永久编号、迟到评分拒绝、取消任务及旧释放清单拦截、预览变化/过期/权限、默认组重建、1205份答卷清单，以及损坏归档、远端位置不符、远端中断后重试、清理期间写入与文件回取拦截、清理后记录事务失败及恢复。测试使用隔离数据，保留测试站原有考试。

界面及实际操作体验由用户本人审查。

内网部署验证使用新建隔离考试，详见《层级删除内网验证》。真实ROS桶及扫描机仍需对应环境验收，远端中断在隔离测试中模拟。
