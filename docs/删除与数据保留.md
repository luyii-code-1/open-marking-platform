# 考试层级删除

管理员可从考试项目、科目、题卡组列表或当前工作区的“更多操作”进入删除。支持删除空记录，也支持删除已有扫描与评分数据的完整业务层级。

## 预览与确认

先生成10分钟有效的预览，显示考试路径、各类业务记录数量、退役题目编号数量、待取消后台任务、重阅队列及失效的释放清单。可下载完整JSON清单，核对业务记录、题目编号、后台任务与文件释放清单的编号。

填写删除原因并勾选已核对范围后确认。只有生成预览的管理员可确认；其他管理员可查看清单。扫描、评分或关联记录发生变化时，原预览被拒绝，需重新预览。重复提交已完成的同一预览返回原结果。

正在执行的相关后台任务或扫描文件释放操作会拦截删除，需等待结束。待执行的关联任务会被取消，旧消息及重试不能重新激活这些任务；原有释放清单失效，防止继续使用旧范围释放文件。

## 影响范围

删除按所有权逐级包含科目、组、题卡、扫描批次、页面、应考名单、答卷、教师分配、阅卷任务、答题图版本、异常与优秀卷、定位及发布/重阅记录。删除科目保留所属考试，删除组保留所属科目及同科其他组。

学生、班级、账号、共享题卡库、赋分方案、图片资产与归档保留。旧业务记录从日常列表与接口移除，原始内容和删除原因保留用于审计。所有已删除业务编号及其题目编号永久退役；创建新记录不能复用旧编号。

原始评分流水与题目结分记录保留；运行中的任务分配状态及重阅队列清除。记录、审计、编号退役及运行状态更新在同一事务完成，任一步失败均回滚。已领取的相关阅卷任务不能继续提交评分。

默认组删除后移除科目的旧默认组关联；返回科目可重新创建默认组，使用全新编号。扫描客户端下一次检查到批次404时冻结本地批次、停止采集，并保留本地原图与队列。

## 扫描文件和归档

当前实现为逻辑删除：本地及远端扫描文件不随记录删除，文件清理策略仍待用户最终选择。需要释放空间时，应在删除前使用项目中的归档与释放流程。删除确认页会明确提示这一点。

删除项目后，已有归档可从管理后台“归档文件”选择原项目下载，ZIP与校验值保持不变。归档文件恢复只处理文件；重新恢复整套历史业务数据应采用删除前的一致数据库备份，在新的数据目录执行《备份与恢复》流程。

## 验证

测试覆盖项目/科目/组范围、父级与同科其他组保留、共享数据和归档保留、评分流水与结分保留、永久编号、迟到评分拒绝、取消任务及旧释放清单拦截、预览变化/过期/权限、失败原子回滚、默认组重建，以及1205份答卷的完整清单与批量删除。测试使用隔离数据，不删除测试站原有考试。

界面及实际操作体验由用户本人审查。

192.168.1.2的独立验证考试已完成真实Worker识读、归档、删除及归档回取校验，原有100条测试成绩保持一致，详见《层级删除内网验证》。
