# 操作与访问日志

管理员在“系统设置 → 操作与访问日志”检索记录。业务审计和HTTP访问分别展示，支持按操作者UUID、目标记录UUID筛选；业务审计可按对象类型筛选，访问记录可按HTTP状态筛选。每页50条，按游标查看更早/较新记录。

业务审计保存对象创建、修改时的快照，与相应业务写入同事务提交。给分记录和实际采用分继续保存在评分流水及任务历史中。管理员可查看快照，凭证字段在检索响应中隐藏；页面只读，不提供修改或删除审计记录。

HTTP访问记录保存已验证的操作者、方法、路由模式、可识别的业务UUID、状态码、处理耗时、网络对端和UTC时间。它不保存请求/响应正文、完整URL或查询字符串；下载凭证路径保留为参数模式。读取失败、权限拒绝、登录失败和未匹配路由同样记录。耗时统计到响应生成，不表示大文件传输总时长；通过反向代理时，网络对端可能是代理节点。

访问日志通过有界队列批量写入SQLite，避免每个读取请求都单独提交日志事务。正常关闭服务时排空队列；写入异常会记录服务端错误，并在管理员接口/页面显示累计错误数。突然断电时尚未落库的访问元数据可能丢失，业务事务审计按数据库事务处理。默认不自动删除日志；数据库备份包含已提交的日志。

生产容器已关闭Uvicorn的原始访问日志，使用上述结构化记录，避免另一份日志记录完整下载地址。手动启动可同样使用 `--no-access-log`。

## 教师成绩可见范围

教师可通过任教班级查看已发布成绩，包括名单中仍为“未扫描”的学生；不要求同时承担阅卷任务。未发布、无关班级及撤销任教关系后的成绩读取被拒绝，跨科分析只包含允许查看的题卡组。

成绩发布、重新开放或任教关系变化时，实时提示会同步刷新考试、科目和题卡组。接口返回401、403或404后清除对应读取缓存；当前评分输入和未保存编辑仍按原流程保留。

## 验证

开发用例覆盖日志权限、游标分页、快照凭证隐藏、访问记录中的密码/令牌/下载凭证隔离，以及任教成绩层级、未扫描名单、无关成绩拒绝和撤回权限。

加入访问日志后，以10800份答卷、10800条历史任务、100位教师、每秒20次请求进行本机ASGI复测：100次领取/给分全部成功且任务不重复；组合请求P95为0.191秒，评分确认P95为0.085秒。该结果不包含真实图像、网络、Redis和生产硬件，页面与生产运行仍需验收。
