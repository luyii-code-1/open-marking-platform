# 制卡与复用

## 考试与分组

在考试项目下创建科目。“不分组（Default）”会同时创建该科目的Default题卡组；选择按学校、年级或卷别分组后，再建立所需题卡组。重复请求Default会复用原组。

进入制卡工作台，新建题卡并选择目标组，设置A3横向/A4纵向与单/双面。双面卷分别设置正背面区域，考号及缺考填涂保留在正面；答题区放在100毫米以下。

## 打印预览与检查

预览使用服务端与最终打印完全相同的PDF生成函数，再由Poppler以110 DPI生成当前面图像。前端只叠加框选和选择标记，标题、考号、缺考框、二维码、客观题选项、富文本和底图均来自该打印稿。

修改后短暂等待自动更新；生成期间显示更新状态，若仍保留上一次预览会明确提示。排版有误时显示错误，数值区域编辑仍可用于修正。框选/移动所得坐标按毫米保存。

草稿可先保存，但必须通过审查并发布后才能导出打印稿。审查包括题号、题型、选项与标准答案、分值、主观题评阅方式及差值、给分规则、区域范围与重叠、富文本是否溢出及图片引用。已发布版式固定，后续使用复制功能建立新草稿；已有扫描批次或答卷的组不能被另一题卡覆盖绑定。

新建草稿尚未取得正式题卡编号时，预览使用临时编号；发布后显示确定的二维码。已发布题卡的预览与导出PDF使用同一编号、修订号及版式。

Linux容器镜像已包含Poppler。手动部署时，`pdftoppm`须可通过PATH找到；缺失、占用或超时会提示更新预览。预览最多同时运行两个渲染任务，临时文件结束后清理，不将草稿写入业务数据库；预览接口需管理员身份并禁用缓存。

## 题卡库

当前实现采用独立版式快照，题卡库的最终组织方式仍等待用户确认。

先保存题卡，再点击“存入题卡库”，填写库内名称与适用说明。快照保存纸张、标题、区域、富文本、底图、答案与给分规则等定义；之后更改原题卡不会改变已保存快照。

“从题卡库创建”可选目标题卡组，或选科目使用Default组。服务器为新题卡及每道题生成新UUID，保存为草稿；沿用的答案及给分规则应在发布前重新核对。原题卡、库内快照与新实例分别维护。

题卡库只对管理员开放。图片通过已有资产编号引用；重新上传会产生新资产编号，旧快照继续引用原资产。当前尚未提供库内编辑、分类与删除入口。

## 验证与边界

开发用例覆盖A4单面、A4双面及A3双面：逐页对比预览PNG与导出PDF在同分辨率下渲染的像素，并核对二维码及前后面。另覆盖Default重复请求、独立快照、实例UUID隔离、教师权限、已使用组绑定保护和给分/版式审查。

这些用例证明生成链路与接口行为；真实打印、跨平台字体、复杂Word粘贴、纸张底图和浏览器交互由用户实际验收。当前未执行浏览器或电脑控制进行UI审查。
