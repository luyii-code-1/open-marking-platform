# Hi-5100S USB 测试插件

在 Windows x64 扫描机上安装厂商驱动并连接 USB，将压缩包完整解压到固定目录。双击 Hi5100S.exe，按设备名称和驱动接口选择 Hi-5100S。在两张纸的正反面分别写 1正、1反、2正、2反；先单面测试自动连续进纸，再重新装纸测双面。双面应返回四幅图，按文件名顺序核对页面内容。独立试扫使用 300 DPI 灰度，在“文档/Hi5100S”下为每次试扫保存原图及 scan.log。报错时可改选另一驱动接口重试。

在扫描客户端的设备设置中选择“外部插件”，添加同一份 Hi5100S.exe，发现并选定扫描仪。重启会恢复选择。替换版本时先停止扫描，再用新版完整文件夹覆盖原目录，保留程序路径；驱动或设备标识改变时重新发现设备。试用期间在客户端菜单选“打开离线页面”可使用随包提供的新版设备设置，已连接的服务仍可使用。

开发时在仓库根目录执行：
```
dotnet publish scanner-plugins/Hi5100S -c Release -r win-x64 --self-contained true -o dist/hi5100s-plugin
```
交互启动为独立测试模式，标准输入重定向时使用 omp-device-1 协议。详见 scanner/DEVICE-PLUGIN.md。
