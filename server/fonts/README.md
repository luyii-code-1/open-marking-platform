OMP Paper Sans is a weight-400 static instance of Noto Sans SC.
Source: https://github.com/notofonts/noto-cjk/tree/main/Sans/Variable/TTF/Subset
License: SIL Open Font License 1.1 (OFL.txt). Original copyright is preserved in the font.
Used for subset embedding in printed answer sheets and rich text.

OMP Paper Sans Bold and OMP Paper Serif Regular/Bold are static instances
at weights 400/700 of Noto Sans SC / Noto Serif SC, from the same upstream
project. Serif source: https://github.com/notofonts/noto-cjk/tree/main/Serif/Variable/TTF/Subset
All fonts use the SIL Open Font License 1.1 in OFL.txt. Upstream copyright
notices remain in the font metadata.

The Italic and BoldItalic files are OMP oblique derivatives made with a
12-degree outline shear; their names identify the modified fonts.
The editor and PDF renderer use these same embedded faces.
